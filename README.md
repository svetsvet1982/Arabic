# 《يوميات سالم》 살렘의 나날 — 두바이 일상 아랍어 대화문 시리즈

UAE 두바이 출신 30대 남성 살렘과 그 주변 사람들의 일상, 그리고 그 일상 속 작은 문제를 풀어 가는 이야기.
아랍어 학습용 대화문 시리즈로, **현대 표준 아랍어(MSA)** 와 **걸프(에미라티) 방언**을 상황에 따라 나누어 쓴다.

- **분량**: 4부 × 15화 × 120턴 = 60화, 7,200턴
- **시간 배경**: 2022–2026년. 각 화가 실제 UAE·두바이 현안과 날짜를 맞춘다.
